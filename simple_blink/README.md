# 💡 Simple Blink

The most basic LED blink program for RP2040 Zero.

## 🔧 Hardware

- RP2040 Zero
- LED connected to GPIO2

## ⚡ What it does

Blinks the LED on and off every 0.5 seconds.

## 🚀 Setup

1. Install CircuitPython on your RP2040 Zero
2. Copy `code.py` to the CIRCUITPY drive
3. The LED will start blinking automatically
